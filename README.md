# Hệ thống đặt vé xem phim

Đề tài hướng tới mục tiêu xây dựng một hệ thống kinh doanh suất chiếu phim, cung cấp các tính năng quản lý suất chiếu, đặt vé theo thời gian thực, đổi thưởng, trò chuyện cho khách hàng.

# Công nghệ sử dụng

 1. Backend: Node + Express
 2. Frontend: React + Vite + Tailwind
 3. Database: MySQL - ORM (Sequelize)
 4. Websocket: Pusher (Realtime)
 5. Cloud store image: Cloudinary
